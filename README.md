A Machine Learning web application that predicts whether a customer is likely to leave (churn) based on customer information and service details.

## 📌 Project Overview

Customer churn prediction is an important machine learning problem that helps businesses identify customers who are likely to stop using their services.

This application uses a trained Machine Learning model to analyze customer data and predict whether a customer will:

- Continue with the service
- Churn (leave the service)

The application provides an easy-to-use web interface built with Streamlit.
